# Security policy

## Reporting a vulnerability

Please e-mail **jean@je4ndev.com** with the subject `[Elozi security]`. Include the affected commit or version,
steps to reproduce, the impact you observed and, if possible, a minimal proof of concept.

**Do not open public GitHub issues, discussions or pull requests for vulnerabilities.** Do not access, change or
exfiltrate data that is not yours, and do not test against the hosted service (elozi.je4ndev.com) without prior
written permission.

We aim to acknowledge reports within 5 business days and to keep you updated until a fix is released. With your
consent we will credit you in the release notes. There is no bug bounty program.

## Scope

- In scope: the source code in this repository.
- Out of scope: third-party services (WhatsApp, Telegram, Meta, Google, Stripe, e-mail providers), social engineering,
  denial-of-service or volumetric testing, and issues that require an already compromised host or browser.

## Supported versions

Security fixes land on the `main` branch.
